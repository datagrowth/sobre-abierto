# Documentación de Sobre Abierto

Cómo instalar Sobre Abierto, usarlo, mantenerlo y entender cómo está hecho. Cada
carpeta es una sección con su índice; la misma estructura se publica en
[docs.sobreabierto.datagrowth.es](https://docs.sobreabierto.datagrowth.es).

- [Empezar](empezar/README.md): qué es, cómo se instala y cómo se deja funcionando.
- [Guía de uso](guia/README.md): qué hace cada pantalla, una página por módulo.
- [Operar](operar/README.md): mantener una instalación en marcha, con copias, reinicios, Drive y seguridad.
- [Referencia](referencia/README.md): variables de entorno, herramientas MCP, roles y preguntas frecuentes.
- [Cómo está hecho](como-esta-hecho/README.md): la arquitectura, la memoria técnica y las carpetas de cada licitación.
- [Contribuir](contribuir/README.md): el entorno de desarrollo, cómo mandar un cambio y cómo avisar de una
  vulnerabilidad.

La Guía de uso es la especificación funcional del producto: un cambio de comportamiento visible actualiza su página
en el mismo PR, y un cambio de diseño, [Arquitectura](como-esta-hecho/arquitectura.md).

El orden de estas listas es el del menú de la documentación publicada: una página nueva se añade al índice de su
carpeta.
