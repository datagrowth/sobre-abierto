# Ficha y oferta

Lo que se ve y se hace dentro de una licitación del Pipeline: la ficha, el equipo, el precio, los antecedentes, la
oferta y lo presentado.

- [La ficha](ficha.md): la cabecera con sus tres preguntas y el go/no-go con cada requisito.
- [Equipo, precios y antecedentes](equipo-precios-antecedentes.md): quién encaja, qué bajas hubo y quién ganó antes.
- [Los cuatro pasos](preparar-la-oferta.md): guion del pliego, decisiones, memoria técnica y presentación.
- [La pestaña Oferta](pestana-oferta.md): el asistente, las comprobaciones y el detalle de la oferta.
- [Revisión y la Mesa](revision.md): lo que se mira antes de firmar y la siguiente tarea.
- [Propuesta y Presentadas](presentadas.md): el registro de lo presentado, el resultado y el histórico.
