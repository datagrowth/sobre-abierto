# Contribuir

Sobre Abierto es software libre (AGPL-3.0-or-later) y acepta cambios. Aquí está cómo levantar el entorno, qué se pide
a un PR y cómo avisar en privado de un fallo de seguridad.

- [Desarrollo](desarrollo.md): requisitos, comprobaciones, datos de prueba y recorridos e2e.
- [Cómo contribuir](../../.github/CONTRIBUTING.md): antes de empezar, reglas del código, commits y PR.
- [Avisar de una vulnerabilidad](../../.github/SECURITY.md): cómo avisar en privado y qué esperar.
